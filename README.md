# Open Derm Trial Atlas — data

Dataset + extraction pipeline backing the Open Derm Trial Atlas, a page on
[superderma.ai](https://superderma.ai) (kolai-website repo). v1 scope: Atopic
Dermatitis, Phase III, systemic therapy, adult population, across five drugs
(Dupilumab, Lebrikizumab, Tralokinumab, Abrocitinib, Upadacitinib).

Pipeline and schema docs land here as the extraction work ships.
